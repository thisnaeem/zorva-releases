# Zorva — Releases

Official Windows releases of **Zorva**, the local-AI clip maker: paste a video
link or drop a file, and Zorva downloads, transcribes and finds the best
moments entirely on your PC — no cloud, no account, no subscription.

Download `Zorva-Setup-<version>.exe` from the
[latest release](https://github.com/thisnaeem/zorva-releases/releases/latest)
and run it. Zorva updates itself from this feed automatically.

Privacy: https://thisnaeem.github.io/zorva-privacy/
